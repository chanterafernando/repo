# My University Website

##  Description
This is a personal university website project created solely with **HTML**. It displays my information, academic interests, and The University.

##  Project Structure

My-University-Website/
├── index.html # Main page (Home)
├── images/
│ ├── Fotografia_F.jpg # Profile photo
│ └── yachay.png # Yachay Tech University logo
└── pages/
├── courses.html # Courses page
├── schedule.html # Schedule page
├── hobbies.html # Hobbies page
├── clubs.html # Clubs page
└── contact.html # Contact page


##  Features
- **Semantic structure** with HTML5 tags (header, nav, main, section, article, footer)
- **Basic navigation** between 6 main sections
- **Personal information** with profile photo
- **Academic interests list** in web development and databases
- **Institutional section** with Yachay Tech information
